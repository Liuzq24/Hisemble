# Supplemental code archive

`Supplemental_Code.zip` is the current journal submission archive. Its SHA-256 is recorded in `Supplemental_Code.zip.sha256`. The root-level `analyses/`, `results/` and `workflows/` provide the current source and tables directly. Start with [Reproduction_Tutorial.md](../Reproduction_Tutorial.md).

`reviewer_analyses/` and `reviewer_results/` retain historical snapshots. Use the root-level analyses and tables for the current revision.
