# Numerical reference results

- `component_ablation/`: full Mouse Cortex, FCA Intestine, MCA Cerebellum; raw numerical records and downsampling reference tables. The unfinished Intestine no-dynamic-sparsification run has no imputed accuracy or completed-run memory value.
- `fca_component_screen/`: all five exploratory FCA candidates, including unfavorable outcomes.
- `robustness/`: eight datasets × ten Leiden seeds (80 runs), plus the three-dataset, 66-run degraded-LSI analysis.
- `lsi_complementarity/`: MCA Cerebellum metrics and neighborhood summaries.
- `lineage_trajectory/`: all six candidates, per-cell numerical DPT and representative ten-root sensitivity. No figure files or UMAP coordinates.

Data inputs and plotting programs are excluded. Reference inputs for MCA Lung A contained 5,122 aligned cells; the existing manuscript dataset table says 5,112. The discrepancy is recorded rather than concealed.
